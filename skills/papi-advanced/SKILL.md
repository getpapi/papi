# papi-advanced

## When to Start a New Conversation

Stay in the same conversation through planning, builds, reviews and release.
After compaction, run `orient`, recover durable work and continue without
rebuilding In Review/Done tasks. Suggest a fresh conversation only for verified
context pressure or the client's documented reload of newly installed tools.
Elapsed time, task count and mode changes do not require a restart.

## Advanced Patterns

- **Cross-project awareness:** Transfer authorized general learnings through
  shared patterns and the doc registry. Keep this chat's project and workspace
  binding fixed. Another project's task, slug or UUID does not authorize a switch
  or per-call project override; obtain explicit target authorization first.
- **Dogfood friction:** When something feels painful in the workflow, note it — the `idea` tool turns friction into improvements.
- **Deferred tasks are intentional:** Tasks moved to Deferred aren't forgotten — they're parked for the right time.
- **Carry-forward items:** Each plan notes carry-forward from the previous cycle. Check them before planning.
